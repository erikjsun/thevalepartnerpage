# The VALE partner page

- Always commit and push directly to `main`. Don't use feature branches. `main` is production: Vercel (team "The VALE", project `thevalepartnerpage`) deploys every push straight to https://partners.thevale.eu. Check that the live page updated after pushing.
- Never say "no strings attached" (or "no-strings", "unrestricted") in visitor-facing copy. Frame it around what sponsorship makes possible instead.
- Follow The VALE Brand Guide (see README): British English, Oxford comma, "The VALE" capitalised as written.
